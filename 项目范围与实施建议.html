本期实施范围建议

内部评估稿 · 2026-09-03

建议的交付主线：离线部署 + TIF/TIFF 输入 + 部署端服务切片 + 现有模型推理 + 可追溯成果。

“一个终端完成”可以保留为用户体验目标，但不应解释成“浏览器上传并切片所有大文件”。用户在同一页面登记、启动、查看进度；原始底图通过部署端指定目录进入，重计算由空间 Worker 在后台完成。

四、必须澄清的 TIFF 与推理关系

无损的做法

按像素窗口切割 GeoTIFF，并保留全部波段、数据类型、NoData、CRS 和仿射变换。LZW 等压缩不是问题；切片只是组织方式改变。

当前代码中的风险

当前部分推理路径会把 TIFF 变成 3 波段 uint8 RGB，再缩放到 512×512 后写 PNG。这一步会丢多光谱、位深和原始空间细节。

实施原则

显示瓦片和分析瓦片分开：PNG/XYZ 只负责浏览；模型读取原始或保留地理参考的分析瓦片；分类结果写成带坐标的标签 GeoTIFF。

五、推理结果编辑的合理设计

正式成果链路：原始 GeoTIFF → 原始像素窗口推理 → 带 CRS 的标签 GeoTIFF → 矢量化与拓扑处理 → 浏览器复核/编辑 → 版本化导出。
阶段应保存的数据首期边界
推理任务项目、矿山、年份、源文件 SHA、模型版本、类别表、CRS、窗口和任务状态固定模型、固定类别，不在线训练
自动成果标签 GeoTIFF、原始 PNG/预览图、GeoJSON 地类面、来源=自动按矿山边界裁剪，过滤碎面，保留原始结果
人工复核选中、顶点编辑、改类别、删除、新增替代面单人编辑；不做自由涂抹和实时多人协同
保存/导出revision、操作者、时间、原因、前后几何、最终 GeoJSON/SHP自动结果不可覆盖；服务器按版本导出
重要限制：现有 512×512 PNG 可以反算近似坐标用于演示，但不建议作为验收级 GIS 成果。正式矢量应在改造后的带地理参考推理链路上重新生成。

六、实施顺序与工期

1–2 人周

P0 运行链路加固

目录导入、就绪标记、校验、磁盘预检、切片任务、取消/重试、离线发布清单。

2–3 人周

P1 地理结果链路

分析瓦片坐标记录、标签 GeoTIFF、矢量化、矿山边界裁剪、地图查看和基础导出。

3–5 人周

P1 编辑闭环

地图编辑、版本审计、并发保护、结果发布和 GeoJSON/SHP 正式导出。

合计按 6–10 人周规划；两人并行时可压缩日历工期，但真实 TIFF 端到端回归、空间坐标正确性和编辑审计不能省略。若加入浏览器 GB 级断点上传、在线训练或复杂多人 GIS，则需重新报价和排期。

七、后续多人协作的最小分工

角色负责范围交付物/验收点
项目/业务负责人地类口径、输入约束、验收样例、甲方边界需求基线和版本签字
GIS/后端目录导入、GDAL 切片、ROI、栅格/矢量服务、数据库空间任务可恢复，坐标和面积可复核
前端地图工作台、底图状态、结果图层、编辑交互编辑版本和错误状态清晰可见
算法模型输入规范、类别表、推理窗口、精度评测模型包、评测报告和适用范围
DevOps/测试镜像/权重清单、离线部署、恢复演练、真实 TIFF 回归可复现发布包和回滚记录

八、建议锁定的四份接口约定

输入影像规范 v1

仅 TIF/TIFF；波段顺序、位深、分辨率、CRS、NoData、最大尺寸和命名规则。

推理与输出规范 v1

任务状态、类别 ID、标签 GeoTIFF、预览图、模型版本、源文件哈希和失败原因。

矢量与编辑规范 v1

字段、面积单位、最小面阈值、版本号、操作者、审计字段和导出格式。

给甲方的简短说明

本期交付采用离线部署模式：用户可在一个终端完成底图登记、切片启动、进度查看和结果浏览。大体积底图通过部署端指定目录导入，由后台空间服务执行切片并保留原始影像，保证任务可恢复和成果可追溯。模型在线训练、未经验证的影像格式扩展、浏览器端 GB 级上传/切片以及复杂多人 GIS 编辑不纳入本期验收；如需增加，应单独进行适配、精度验证和报价。
代码依据：miner/src/components/ProjectWorkspace.vue（导入工作台）、backend/applications/project_hub/spatial_service.py（候选扫描与登记）、backend/applications/project_hub/spatial_worker.py（GDAL 切片与续跑）、backend/applications/kml_roi/raster_ops.py 和 backend/applications/interface/mmseg_segmentation.py（当前 TIFF/RGB/PNG 推理路径）。本文件是范围与验收建议，不替代正式合同条款和精度报告。
