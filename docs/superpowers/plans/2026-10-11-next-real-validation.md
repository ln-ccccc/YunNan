# 真实数据下一轮修复与验收计划

> 按模块并行执行，在集成分支复核契约和代码，再做真实服务与浏览器验收。用户已授权继续实施。

**目标：** 补齐激活底图原影像推理、修复 ROI 预处理开关无效和跨网格变化统计，补测真实矢量编辑与任务恢复。

**架构：** Miner 只提交公开资产标识，由后端解析受控源栅格；ROI 推理仅按显式参数处理暂存输入。变化矩阵使用带地理参考的类别栅格，通过最近邻对齐计算共同有效覆盖，不能按 PNG 左上角或缩放进行空间比较。

**基线：** `1177231`；工作树 `real-next-validation-20261011`，分支 `codex/real-next-validation-20261011`。主目录用户修改不纳入提交。原始影像和权重只读，共享测试库、输出、端口均隔离。

## 任务与最小验证

- [ ] 底图推理。主模块 `project_hub/inference_inputs.py`，消费者为 `/inference/jobs`、资产/就绪读模型和 Miner 推理入口。先更新架构契约与 fixture；复现仅有激活底图时不可推理，再测试无源、跨项目、非活动版本和原有数据集兼容。新增可选公开资产标识，保留已有参数；不迁移表和原文件。
- [ ] ROI 预处理。主模块 `kml_roi`，消费者为 GeoView 的上传与任务链。追踪 `prehandle/denoise` 的编号与已有算法；先测试参数丢失，再验证显式参数从请求到暂存输入，默认不处理。同步输入/输出契约；不改变固定模型的默认预处理、类别和空间网格。
- [ ] 空间变化统计。主模块 `kml_roi/change_matrix.py`，消费者为 `tiles.py` 与 `project_hub/inference_results.py`。先用错位窗口/分辨率/CRS 标签复现左上角比较错误，再利用对应 `_label.tif` 对齐至新期网格。测试共同覆盖、NoData、无交集、缺地理参考及同网格兼容；缺元数据不得伪造空间对齐。
- [ ] 真实服务。新测试库放 Linux 存储，记录与原库的复制来源；只复用上一轮已冻结数据，不写回。真实 Maus 矿山与 GEHI TIFF 验证底图推理、预处理、成果重读；真实 S2 不同网格输入核对变化统计。GPU 禁止 CPU 回退。
- [ ] 连续 GUI。真实鼠标/键盘补测删除、合并、简化、双窗口 409 冲突和未保存保护；补测底图版本恢复与取消。重开页面确认持久化，实际打开截图检查显示；普通与减少动态效果连续切换并采样卡顿。
- [ ] 集成与交付。各模块现有 Node 测试/构建及相关后端 unittest；集成 diff 复核、真实 GUI 证据及失败/未测项记录。推送 `codex/` 分支供评审，不自行合并或部署。

## 风险和边界

新的预处理只作用于用户显式选择的处理，不据此承诺模型精度。变化统计共同覆盖会与旧错误比较得到不同数值，需明确目标网格与像素口径。Linux 测试库不证明生产 MySQL 或原 Windows 挂载库性能。GB 文件、完整离线恢复与科学精度只在有真实执行证据时声明通过；本轮未覆盖项继续保留。
