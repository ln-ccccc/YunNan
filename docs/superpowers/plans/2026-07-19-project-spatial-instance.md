# 项目级空间实例实施计划

> 执行时采用测试驱动，逐任务完成 RED、GREEN 和回归检查。当前目录无有效 Git 元数据，不执行提交或 worktree 操作。

## 实施顺序

1. 新增空间资源、空间任务模型、项目空间状态和受控存储路径。
2. 实现 KML/GeoJSON 导入、字段映射、标准化、自动绑定和资源版本切换。
3. 实现 GeoTIFF 候选扫描、注册、GDAL 校验和范围相交检查。
4. 新增 spatial-worker，支持切片、进度、取消、重试和重启恢复。
5. 项目化 GeoJSON、瓦片、统计、指数、趋势和解译接口；停用全局数据兜底。
6. 实现四步向导、资源状态、项目化地图路由和切换时状态清空。
7. 注册并迁移大理资源，更新 Compose、存储挂载和离线部署文档。
8. 完成双项目、断网、跨项目拒绝、测试、构建和容器验收。

## 固定约束

- 矿山首版支持 KML、GeoJSON，上传上限 50 MB。
- 底图支持单个 GeoTIFF/TIF及同名辅助文件，通过受控导入目录注册。
- 默认瓦片层级 8–15，每类资源只保留当前版和上一版。
- 新版本失败或取消不得影响当前活动资源。
