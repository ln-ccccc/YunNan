# Miner 与解译平台共享登录设计

## 目标

管理员在 Miner 登录一次后，点击“解译平台”直接进入主系统的 `/segmentation` 管理界面，不再重复输入密码。

## 根因

- Miner 通过 `localhost` 登录并获得会话 Cookie。
- 主系统把后端地址生成为 `127.0.0.1:5008`，浏览器不会把 `localhost` 的 Cookie 发送给 `127.0.0.1`。
- Miner 的按钮仍生成旧式 `/#/segmentation` 地址，而主系统使用 history 路由。

## 方案

1. 主系统在浏览器中使用当前页面的主机名访问后端，只保留后端端口配置。
2. Miner 跳转时沿用当前页面的主机名，并固定进入 `/segmentation`，清除旧 hash。
3. 保留现有服务端会话、账号校验和退出登录逻辑，不传递密码或 URL 令牌。

## 验证

- 回归测试覆盖主机名统一和 `/segmentation` 跳转地址。
- 分别构建 Miner 与主系统前端。
- 使用同一浏览器会话登录 Miner，点击按钮后确认主系统会话已认证并进入 `/segmentation`。
- 确认退出登录后受保护页面仍要求重新登录。

## 边界

- 不取消登录。
- 不修改管理员密码、数据库或后端权限模型。
- 不引入新的 SSO 服务或令牌协议。
