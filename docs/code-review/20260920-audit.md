## 决策清单（等负责人）

1. **运行栈挂载指向**：维持 worktree（UI 刷新验收中？）还是切回 main？切回会重启 5 个容器并中断当前运行态。本轮所有修复只落在主树，运行栈需切回（或重建镜像）后才生效。
2. **镜像烘焙口令**：yunnan-runtime:current 的 ENV 含疑似真实 MYSQL_PASSWORD。建议重建镜像（Dockerfile 不落该 ENV，凭据只走 compose --env-file），并把已在外的 tar 视为受污染。重建动作大，需授权。
3. **.env 交付口令**：本地 .env 三口令同为 yndks；部署脚本已加强度闸（≥8 位且不同），正式交付前需换强口令。
4. **compose 五容器以 root 运行**：加 `user:` 需同步处理卷属主，影响面大，建议单独排期。
5. **useWeather 浏览器直连公网天气 API**：内网部署必挂 + 矿山坐标外发。改后端代理/加开关/禁用三选一。
6. **kml_roi/service.py + kml_merge.py 死链路**：生产零调用但测试在测；删除属功能决策（该路径若复用会直写 miner/ 目录，违反推理运行时契约）。
7. **KML 共享目录同名覆盖语义**：保留现行为（同名替换）或改按用户/UUID 隔离；改存储命名会连带 kml-roi 引用方式。
