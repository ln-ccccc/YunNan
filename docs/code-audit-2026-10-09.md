## 本次已修复

1. 智能解译地图入口携带选中的项目 ID，无项目时禁用。
2. 成果映射使用独立 `editorTargetsSeq`，成功及失败均校验项目；翻页后切项目不再丢弃合法响应。
3. 工作台接收导出/配置快照下载事件，鉴权获取 Blob、保存正确文件名；失败在面板显示，重试可恢复。
4. 工作台和地图页的退出事件接入实际注销流程。
5. Miner 折叠导航保留 SVG 图标、可访问名称、当前项；短窗口可滚动到最后一项。退出图标改用 SVG，避免本机缺失电源符号字形；GeoView 折叠图标覆盖 Element Plus 内联缩进并保留可访问名称。
6. 无项目上下文时不挂载地图，消除隐藏地图初始化“缺少有效项目 ID”的控制台异常；有效项目继续使用原 v-show/key 生命周期。
7. GeoView 手机导航收起期间固定占位，展开浮层保留主内容位置；表单、工具栏、编辑器响应式适配。
8. Miner 手机地图保留最小可用宽度和内部横向滚动；页头不再竖排挤字，图例在浅底图上可读。经纬网按钮通过 MapContainer slot 相对地图定位，不再依赖统计侧栏宽度。
9. 减少动态效果覆盖两个应用及 GeoView teleport 图片预览、弹窗和消息根节点。

修复事件的组件回归先在原代码失败，再在修复后通过；布局与交互问题以改前/改后 GUI 截图验收。没有扩大为训练、GIS 算法或部署重构。

## Material 与 Motion

布局参考 [Apple Layout](https://developer.apple.com/cn/design/human-interface-guidelines/layout)：相关信息分组、突出主任务、保留留白、按窗口调整侧栏和内容层级。材质参考 [Materials](https://developer.apple.com/design/human-interface-guidelines/materials)，动效参考 [Motion](https://developer.apple.com/design/human-interface-guidelines/motion)。边缘高光参考 [CSS/SVG 玻璃演示](https://kube.io/blog/liquid-glass-css-svg/)。

实现是 Web 的玻璃材质近似，未声称复刻 Apple 原生光学着色器。采用本机字体、冰川白/墨青/矿山绿、半透明高光与内边缘。玻璃集中于导航、摘要、工具栏和浮层；表单与长数据内容使用清晰底色，分类颜色及影像保持原语义，不引用外部 CDN。

| 操作 | 反馈 |
| --- | --- |
| 按钮按压 | 120ms，约 2–3% 缩放，配合颜色/阴影 |
| 导航与状态 | 180–240ms 选中反馈、标题轻位移/淡入、状态颜色/淡入 |
| 面板展开 | 240ms grid 高度过渡；快速反向切换保持正确终态，离场禁止点击 |
| GeoView 路由/弹窗 | 240ms 淡入和 6px 位移，保留既有路由/地图生命周期 |
| 减少动态效果 | 停止位移与过渡；Element Plus 保留极短事件时长以完成弹窗生命周期 |

侧栏玻璃背景放在独立伪元素，避免材质与按钮动画共用绘制层；不为整个页面强制创建动画纹理，不给地图加整体位移动画。提供减少透明度、模糊不支持、强制颜色回退。原地图侧栏有 GPU 合成伪影记录，仍保留稳定实色。
