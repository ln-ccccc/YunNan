**30. ⬜ P2 生产构建输入来自多个快照，迁移后可能与本地代码不一致** — `docker-compose.prod.yml:119/253`、`docker/check-node-deps.mjs`。混用宿主源码、镜像内 HTML/配置、不同来源依赖；GeoView public/ 构建配置未与 src 同源；依赖预检只查可解析不查锁文件版本。修复：构建输入统一为同一源码快照+锁文件；推荐构建期产出版本化静态制品；暂留启动构建则统一全部输入并校验版本清单。验收：隔离目录按交付包启动（无本机覆盖层），核对页面/依赖/构建哈希。
