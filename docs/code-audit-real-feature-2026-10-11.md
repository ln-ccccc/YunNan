# 真实数据功能验收与修复记录

结论：现有功能不能全部称为可用。真实矿山与双年遥感影像已完成 CUDA 推理、正式发布、光谱计算和持久化读回；当前底图没有直接一键推理入口，需要把同源原 TIFF 登记为 imagery 后选择。显示用 XYZ 瓦片不是推理输入。

本轮代码在 `codex/real-data-acceptance-20261011`；使用临时 SQLite、独立存储和 loopback 端口，原影像与权重只读。不代表 main、生产 MySQL、客户设备或分类准确率通过。原工作区 `main d0b37b5` 的用户未提交测试未覆盖。

## 已修复

- 源面积显式选择 m²/km²，后端一次换算；源 AREA、几何与文件保持，`area_m2` 明确供消费者读取。未映射面积允许导入，映射面积但未选单位禁止提交。旧错误项目不自动覆盖，重新导入形成版本。
- 真实 UTM 影像按 CRS 线性单位与仿射行列式统计面积，避免把米当经纬度；地理 CRS 仍为中心纬度近似，未知 CRS 不猜。
- 项目切换时过期推理响应失效；推理弹窗使用统一浅玻璃材质、开合/按压/状态反馈和减少动态效果。
- Worker 成功/失败活动审计不依赖 Web schema；Worker 镜像显式包含成果发布闭包与冷启动自检。
- 已登记 incoming 原影像可受控下载；项目、数据集与输入白名单一致。
- 自动基线原样几何可改类，新几何仍严格检查 ROI；删除不必要的小数圆整，原标签/自动基线不覆盖。
- 20+1 分页筛选回第一页，异步旧响应失效，矿山资源改变刷新清单。
- 候选刷新按登记ID或未登记非空storage_key保留原输入；来源消失则清空，避免同名同尺寸影像替换选择。
- 已登记的裁剪/切片影像只呈现数据集候选，扫描同规范路径不再重复；不同文件的同名影像不合并。
- 撤除浏览器无法解码且丢失地理语义的 TIFF 裁图入口，普通原文件上传保留；地理裁剪沿用影像管理。
- Draw 控件、键盘画布目标和光标对齐 MapLibre；离线地图使用已有边界/缩放范围并提前定位，旧地图加载回调不能操作新地图。
- 项目卡片只查任务元数据，BFF按完整会话与查询合并未完成的相同列表请求；完成即清理，写入后的刷新重新读。
- 将线性斜率文案改称“趋势方向”，保留旧 DTO；修正逐 FID 发布文档，避免承诺整个多 FID 任务原子回滚。

## 未实现与未验收

当前底图一键推理、全矿山趋势报告生成、真正 Mann–Kendall、跨CRS/分辨率/窗口变化配准、项目GE/ROI推理应用预处理参数、整个多FID任务原子回滚及部分取消/批量下载GUI入口未实现。本轮记录这些缺口，没有新增算法或改模型预处理。
